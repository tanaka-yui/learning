> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `10_container/04_gitops_argo/` に GitOps mono-repo (envs/dev/stg/prod + base) を作り、Argo CD / Flux / Argo Workflows / Argo Rollouts / Argo Events / GHA Runner Controller の 6 tool + AWS 対比 (CodePipeline/StepFunctions/EventBridge の Terraform stub) を「動く」形で載せる。
